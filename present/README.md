# Beside x SAP: ฉบับผู้นำเสนอ (presenter)

สำเนาของ `../beside-sap-new` ที่ลดจำนวนคลิกต่อหน้าเหลือ 0-1 คลิก (ต้นฉบับไม่ถูกแก้) ใช้เดินสไลด์ด้วยมือ ไม่ใช่สำหรับอัดวิดีโอ

## วิธีเปิด
- เปิดไฟล์ตรง ๆ: `file:///Users/artit/Desktop/deck-system/projects/beside-sap-present/full/n1.html` (หน้าแรก)
- หรือรันเซิร์ฟเวอร์ในโฟลเดอร์นี้ เช่น `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000/full/n1.html`
- ต่อ `?auto` ท้าย URL = เล่นทุกเอฟเฟกต์รวดเดียว ไม่ต้องคลิก

## ปุ่ม
- ไปข้างหน้า: Space / Enter / → / ↓ / PageDown / คลิกขวาของจอ
- ย้อน: ← / ↑ / PageUp / Backspace / คลิกซ้าย 20% ของจอ
- ถ้าหน้านี้ไม่มีเอฟเฟกต์เหลือ ปุ่มไปข้างหน้าจะเปลี่ยนไปหน้าถัดไปเอง

## ต่างจากฉบับเต็มอย่างไร
- ฉบับเต็ม: 1 คลิก = 1 เอฟเฟกต์ (หน้าละ 4-27 คลิก)
- ฉบับนี้: เปิดหน้าแล้วเล่นจุดแรกให้เอง, คลิก 1 = โชว์ครบทั้งหน้า (หน้าละ 1 คลิก)
- ภาพสุดท้ายของแต่ละหน้าตรงกับฉบับเต็ม ไม่มีอะไรหาย แต่ระหว่างคลิกเอฟเฟกต์ที่ข้ามจะเล่นต่อเนื่องด้วยความเร็วปกติ หน้ายาว (เช่น prd, fin, po) จึงอาจใช้เวลาเล่นหลายวินาทีหลังคลิก กดซ้ำเพื่อข้ามไปจบทันที
- แอนิเมชันพื้นหลังที่วนซ้ำยังทำงานตามเดิม
- โค้ดที่ต่าง: `full/ctl.js` ฟังก์ชัน `compute()` (คัดจุดหยุด) และธง `deck.presenter=true`
